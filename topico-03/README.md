# Atividade prática individual - Tópico 3

## Nível realizado

Nível 2 - Intermédio

## Objetivo

Criar e publicar um serviço web em ambiente Linux utilizando
o servidor web Nginx.

## Ambiente utilizado

Máquina virtual Linux.

## Rota de publicação

Nginx

## Ficheiros criados

- site/index.html
- site/sobre.html
- site/style.css
- comandos.txt
- publicacao.md
- validacao.md
- README.md

## Local de publicação

/var/www/html/topico-03/

## URLs testados

- http://localhost/topico-03/
- http://localhost/topico-03/sobre.html

## Evidências produzidas

A pasta evidencias/ contém os prints e outputs utilizados
para comprovar a realização e validação da atividade.

## Dificuldades encontradas

Durante a atividade foram verificadas as condições do servidor
Nginx, a localização dos ficheiros e o acesso ao serviço através
do navegador e do comando curl.
