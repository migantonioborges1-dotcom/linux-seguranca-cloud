Publicação de um Serviço Web

Esta página foi criada no âmbito da atividade prática individual do Tópico 3 da unidade de Linux, Segurança e Cloud.

O objetivo é criar, publicar, validar e documentar um pequeno serviço web utilizando um servidor web em ambiente Linux.

Componentes utilizados

🐧 Linux Sistema operativo
🚀 Nginx Servidor Web
🌐 HTML5 Estrutura
🎨 CSS3 Design
📦 Git Versionamento
💻 GitHub Repositório
🎓
APRENDIZAGEM

O que aprendi

Durante esta atividade foi possível compreender as principais etapas necessárias para disponibilizar um serviço web funcional num ambiente Linux.

  • ✓ Criar uma estrutura básica de um serviço web.
  • ✓ Configurar e utilizar o servidor Nginx.
  • ✓ Publicar páginas HTML através de um servidor web.
  • ✓ Validar o acesso utilizando navegador e curl.
  • ✓ Documentar o processo e respetivas evidências.
