OBJETIVO

Criar e publicar um serviço web

O objetivo desta atividade é demonstrar a capacidade de criar e publicar um pequeno serviço web num ambiente Linux.

A atividade foi realizada no âmbito do Tópico 3, utilizando Nginx como servidor web.

🛠️
TECNOLOGIAS

Tecnologias utilizadas

🐧 Linux Ambiente
🚀 Nginx Servidor Web
🌐 HTML5 Estrutura
🎨 CSS3 Estilos
🔍
PROCESSO

Etapas realizadas

01
Criação

Desenvolvimento do conteúdo HTML e CSS.

02
Configuração

Configuração do servidor Nginx em Linux.

03
Publicação

Disponibilização do serviço através do servidor web.

04
Validação

Testes através do navegador e do comando curl.

05
Documentação

Registo do processo e das respetivas evidências.
